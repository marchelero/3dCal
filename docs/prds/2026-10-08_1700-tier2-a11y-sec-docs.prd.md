## 1. Problema (verificado contra el fuente, 2026-10-08)

1. **SEC-01 (paywall hardening):** el boot de `EntitlementNotifier` solo dispara el sync con la
   store cuando el cache dice **Pro** (`entitlement_notifier.dart:90-101`); el camino **Free**
   (`:103-117`) consulta únicamente la DB local y nunca la store. Reinstalación o compra en otro
   dispositivo ⇒ usuario Pro en la store ve "Free" hasta que presiona "Restaurar" a mano.
   (El audit 2026-08-13 #2/#3 ya está implementado: sync en boot Pro + `proRevocationStream`.)
2. **SEC-03 (firma de backups):** `backup_service.dart` exporta JSON plano por `share_plus`, sin
   integridad; el import solo valida schemaVersion/estructura/5MB. Un archivo editado a mano se
   restaura silenciosamente.
3. **SEC-12 (URLs legales placeholder):** `app_constants.dart:158,162` = `u3dcal.bo/privacy|terms`
   con "reemplazar antes de publicar". **Diferido a release checklist** (decisión del dueño: no hay
   URL real todavía).
4. **a11y contraste:** 2 fallos AA verificados con la fórmula WCAG:
   - texto blanco sobre `blueSuccess #1E88E5` (snacks de éxito) = **3.68** (< 4.5).
   - `inkSoft #5A6B85` sobre `surfaceContainerHighest #DCE5F0` = **4.26** y sobre
     `surfaceContainerHigh #E3EAF3` = **4.47** (< 4.5 para texto normal).
5. **a11y text-scale:** **0** usos de `textScaler`/`textScaleFactor` en `lib/` (57 `fontSize`
   hardcoded); no hay test que bombeé pantallas con escala > 1 → clipping/overflow silencioso en
   teléfonos con texto grande.
6. **Docs stale:** `README.md:9` dice "MVP 1.0.0 … `flutter test` 118/118" (hoy **947** y versión
   `0.6.0+13`); `docs/PROJECT.md` menciona Flutter 3.22/Dart 3.x (hoy 3.47.4/3.13.3) y describe
   stack viejo; `PRODUCT.md` está en la raíz.

## 5. Requisitos por ítem

### T2-1 — SEC-01: boot Free consulta la store
- El camino Free del `build()` dispara `_syncEntitlementWithStore()` fire-and-forget (idéntico
  patrón que el camino Pro), con un manejo nuevo para `storeActive == true` estando en Free:
  **hidratar** (fila activa en repo si no existe + `cache.setActive` + emitir `EntitlementPro`)
  sin pisar timestamps más nuevos.
- Race guards idénticos a los existentes (proRevocation, purchase/restore en vuelo).
- `storeActive == null` (web/offline) → no-op, comportamiento actual intacto.
- **Tests:** boot Free + store devuelve `true` → emite Pro y persiste; store `null` → sigue Free;
  boot Pro sin cambios (regresión).

### T2-2 — SEC-03: firma de backups
- Export: payload con HMAC-SHA256 (key por dispositivo generada en el primer uso, guardada en
  SharedPreferences vía `entitlement_cache`-style wrapper propio; ya que no hay
  `flutter_secure_storage`, el threat model es "archivo editado fuera de la app", no root).
- Import: firma presente y correcta → OK; **ausente (backup legacy) → importa con aviso
  `debugPrint` + acepta** (no romper migración); **mismatch → rechaza con error localizado**.
- Sin cambios en schema de tablas; el campo firma va en el envoltorio JSON (fuera del `BackupData`).
- **Tests:** roundtrip firma válida; payload alterado → rechazado; backup sin firma (legacy) →
  aceptado; key nueva dos veces idempotente.

### T2-3 — a11y contraste
- `AppTheme.blueSuccess` `#1E88E5` → candidato que alcance ≥ 4.5 con blanco (medido:
  `#1976D2` = 4.60, `#0D6ECD` = 5.09). Se elige el más cercano visualmente sin romper dark mode.
- `inkSoft #5A6B85` → oscurecer lo justo para ≥ 4.5 sobre `#DCE5F0` (surfaceContainerHighest claro).
- **Test unitario** con la fórmula WCAG sobre los pares reales (light + dark) — falla si alguien
  degrada los tokens de nuevo.
- Sin cambiar el resto de los 74 `Color(0x`.

### T2-4 — a11y text-scale
- Test harness que bombea pantallas clave (home, calculator, settings, history, paywall, detail)
  con `MediaQuery(textScaler: 1.5)` y afirma **cero excepciones de overflow/layout**.
- Arreglar únicamente los clipping que el harness descubra (alturas fijas / Rows sin wrap).
- No reescribir layouts sanos.

### T2-5 — Semantics críticos
